Problem Statement:


Engineering students, developers, and analysts often need to perform diverse mathematical operations—ranging from scientific functions and matrix manipulations to solving equations, statistical analysis, and number theory. Traditionally, these tasks require multiple tools: scientific calculators, spreadsheets, or specialized software. Switching between them is inefficient, error-prone, and time-consuming.


Objectives:


Design a modular Java program with separate functions for each mathematical category.

Provide a clear, menu-driven interface for easy navigation between features.

Implement robust error handling to manage invalid inputs gracefully.

Ensure accurate calculations across diverse domains (scientific, algebraic, statistical, number theory).

Create an extensible framework that allows new features to be added easily.

Deliver formatted, user-friendly outputs for clarity in academic and professional use.


Scope of the Project:


Functional Scope:


Scientific Functions: log, exp, sin, cos, tan, inverse trig functions, and hyperbolic functions.

Matrix Operations: addition and multiplication of square matrices.

Equation Solvers: quadratic equations and linear systems (2×2).

Statistics: mean, median, and standard deviation for datasets.

Power & Factorial Calculations: efficient computation of exponents and factorials.

Prime Number Utilities: primality testing and prime number generation.


Non-Functional Scope:


Efficiency: Fast calculations with minimal overhead.

Portability: Runs on any platform with a Java Virtual Machine (JVM).

Simplicity: Intuitive menu-driven interface with clear prompts.

Reliability: Exception handling ensures safe termination and user guidance.


Target Audience:


Engineering students: Solve coursework problems in mathematics and computer science.

Developers & analysts: Quickly test mathematical logic without switching tools.

Educators & learners: Use as a teaching aid for demonstrating core mathematical concepts.

Enthusiasts: Experiment with number theory, statistics, and algebra in a lightweight CLI utility.
